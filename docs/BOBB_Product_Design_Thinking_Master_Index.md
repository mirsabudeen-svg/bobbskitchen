## 🎯 RESEARCH FRAMEWORK (Applied to All 10 Products)

Each product has comprehensive research across **9 sections:**

```
SECTION 1: TECHNICAL CONSTRAINTS
├─ Print area dimensions
├─ Print methods available
├─ Material specifications
├─ Hardware/assembly requirements
├─ Durability expectations
└─ Hard-to-print areas

├─ Composition approaches (3-5 options)
├─ Balance & visual hierarchy
├─ Typography considerations
├─ Color psychology
├─ Style-specific rules
└─ Medium-specific constraints

SECTION 3: USER PSYCHOLOGY
├─ Primary motivations (5 levels)
├─ Usage context & scenarios
├─ Viewing distances
├─ Emotional connections
├─ Longevity expectations
└─ Design implications

SECTION 4: MANUFACTURING & MATERIAL SCIENCE
├─ Production process steps
├─ Material behavior
├─ Quality control points
├─ Durability factors
├─ Common production challenges
└─ What designers need to know

SECTION 5: CULTURAL & REGIONAL RESONANCE
├─ 8 Kerala-inspired theme options
├─ Sensitivity guidelines
├─ Avoided topics (what NOT to do)
├─ Authentic representation
├─ Design language for each theme
└─ Cultural respect principles

SECTION 6: DESIGN METHODOLOGY
├─ Step-by-step process (Empathy → Define → Ideate → Prototype → Test)
├─ Real customer story example
├─ Multiple design direction options
├─ Visual variation creation
├─ Refinement process
└─ Final approval checklist

SECTION 7: QUALITY CHECKLIST
├─ Composition verification
├─ Technical compliance
├─ Durability assessment
├─ Cultural sensitivity check
├─ Brand alignment
├─ Usability validation
└─ Before-approval verification

SECTION 8: COMMON MISTAKES
├─ Top 10 mistakes to avoid
├─ Why each is a problem
├─ What to do instead
├─ Examples of failures
└─ Best practices

SECTION 9: SYSTEM PROMPT
├─ Copy-paste ready for AI agents
├─ Critical constraints
├─ Design principles
├─ Cultural guidelines
├─ Output format specification
├─ Validation checklist
└─ Philosophy & mindset
```
