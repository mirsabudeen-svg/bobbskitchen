## Cross-Product Summary

### Top 3 Technical Bottlenecks by Product Category

| Category | Primary Bottleneck | Secondary Bottleneck | Solution |
| :-- | :-- | :-- | :-- |
| **Fabric (T-shirt, flip-flops, shoes)** | Flex cracking | Color fastness | Use DTF/sublimation, flexible ink [^18][^37] |
| **Hard Surface (phone, laptop, bottle)** | Model accuracy | UV fade resistance | UV direct print, exact templates [^25][^22] |
| **Sticker (helmet, bag, keychain)** | Edge lift | UV fade | Cast vinyl + lamination [^30][^31] |

### Kerala Cultural Design Guidelines (Universal)

| DO | DON'T |
| :-- | :-- |
| Use Kasavu white-gold palette | Use sacred temple imagery on ground-level items |
| Use Pookalam geometric patterns | Use generic "Indian" motifs instead of Kerala-specific |
| Use Malayalam script correctly (verify spelling) | Use religious symbols on helmets/shoes/flip-flops |
| Reference Kerala geography (backwaters, beaches, waterfalls) | Use tourist clichés without cultural context [^5][^6][^7] |

### Minimum Quality Standards by Product

| Product | Minimum DPI | Print Method | Durability Test |
| :-- | :-- | :-- | :-- |
| T-shirt | 300 | DTG / DTF | 50 wash cycles [^2][^3] |
| Keychain | 600 | UV print | 1000 attachment cycles [^10][^11] |
| Flip-flops | 300 | Sublimation on PU | 10,000 flex cycles [^18][^19] |
| Laptop skin | 300 | Digital print (3M vinyl) | 7-day edge lift [^22][^24] |
| Phone case | 600 | UV direct | 1000 scratch cycles [^25][^27] |
| Helmet sticker | 300 | Cast vinyl + lamination | 200hr UV exposure [^30][^31] |
| Water bottle | 300 | UV direct (steel) | 100 dishwasher cycles [^32][^34] |
| Bag sticker | 300 | Vinyl + lamination | 500 abrasion cycles [^30][^35] |
| Shoes | 300 | DTF (canvas) | 10,000 flex cycles [^36][^37] |
| Accessories | 300 | Match to material | Functional test + wash [^15][^17] |
